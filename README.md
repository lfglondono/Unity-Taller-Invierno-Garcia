
# Escena Invernal de Rescate

Proyecto realizado en Unity para la creación de una escena 3D invernal que representa una patrulla de policía atrapada en una tormenta de nieve, utilizando iluminación, jerarquías, scripts y sistemas de partículas.

## Desarrollo

1. Crear terreno nevado y coche de policía parcialmente enterrado.
2. Crear jerarquía de luces de emergencia rojas y azules.
3. Implementar el script `SirenRotation.cs` para controlar la rotación de las sirenas.
4. Agregar sistema de partículas de nieve (`Global_Blizzard`).
5. Agregar sistema de partículas de humo (`Exhaust_Smoke`).
6. Configurar la iluminación y composición de la escena.

## Versión

Unity 6000.6.8f
